# Assessment Folder

This folder contains the Data Engineering Assessment materials.

## Contents

- **Assessment_Instructions.md** - Complete assessment requirements and rubric
- **Quick_Start_Guide.md** - Quick reference to get started
- **drilling_operations.db** - Your SQLite database (create this during the assessment)

## Folder Structure

Participants should organize their work as follows:

```
Assessment/
├── README.md                       # This file
├── Assessment_Instructions.md      # Full instructions
├── Quick_Start_Guide.md           # Quick reference
├── drilling_operations.db         # SQLite database (you create this)
├── ERD_Design/                    # Your ERD and documentation
│   ├── ERD_diagram.png
│   └── design_explanation.md
├── create_schema.py / create_schema.sql    # Schema creation script
├── etl_pipeline.py                # ETL implementation
└── validation_queries.sql         # Validation queries (optional)
```

## Data Source

The assessment uses the dataset located at:
```
../../data/DataForAssessment.csv
```

## Getting Started

1. Read **Assessment_Instructions.md** for complete requirements
2. Use **Quick_Start_Guide.md** for quick reference
3. Create your folder structure
4. Begin with Task 1: ERD Design

## Submission

1. When complete, compile your Assessment working files into:
```YourName_Python_Assessment``` folder
2. Include all files listed in the **Assessment_Instructions.md**.
3. Upload your assessment into your own branch in this GitHub repository:
[Data-Journey-Kickstart-Python-Assessment](https://github.com/alia-jamal/Data-Journey-Kickstart-Python-Assessment.git)
